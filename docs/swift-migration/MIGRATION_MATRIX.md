## 2. Existing Bugs & Architectural Weaknesses Fixed in the Swift Rewrite

| ID | Category | Legacy Rust Issue / Weakness | Native Swift Fix |
|---|---|---|---|
| **BUG-01** | Architecture / Maintainability | `src/main.rs` was a 5,196-line monolithic file mixing `MainWindow`, `AppDelegate`, toolbar construction, split-view layout, document info, error dialogs, keyboard shortcuts, and PDF notifications with hundreds of raw `unsafe { msg_send![...] }` calls. | Decomposed into clean, modular, type-safe `@MainActor` Swift controllers (`AppDelegate`, `MainWindowController`, `RightInspectorController`, `UtilityWindows`, `PDFReaderCoordinator`) using compiler-checked AppKit & PDFKit APIs. |
| **BUG-02** | Memory Safety & Pointer Lifetimes | Delegates in Rust (`WorkspaceOutlineDelegate`, `PdfSearchDelegate`, `BookmarksDelegate`, `CommandPaletteDelegate`) relied on raw unretained pointers (`setTarget: ptr`, `AtomicPtr<c_void>`) to avoid `Retained` cycles, risking dangling pointers if views outlived controllers. | Uses native Swift `weak var` references and structured `Task` lifecycles, completely eliminating manual raw pointer casting and dangling pointer hazards. |
| **BUG-03** | Concurrency & Background Tasks | Background threads in Rust (`std::thread::spawn`) communicated back to the main thread by stashing payloads into global `Mutex<Option<...>>` statics (`COMPLETED_NODES`, `INDEX_RESULT`, `OCR_RESULT`) and firing selector callbacks (`performSelectorOnMainThread`). Concurrent operations could overwrite pending slots. | Uses Swift 6 structured concurrency (`Task`, `@MainActor`, `async/await`) with per-request cancellation tokens, eliminating global mutable result slots and race conditions. |
| **BUG-04** | Multi-Tab Search & Outline State Bleed | Switching tabs in Rust updated `PDFView.document` and refreshed the outline, but an in-flight async search from a previous tab could still deliver results to `PdfSearchDelegate` after switching tabs. | `PDFSearchController` cancels any active search and binds results strictly to the current `PDFDocument` instance identity. |
| **BUG-05** | iCloud Polling Overhead | `iCloudTimerFired:` ran a repeating `NSTimer` polling ubiquitous status when downloading. | `ICloudCoordinator` scopes monitoring strictly to active cloud-item downloads and stops immediately once all monitored items become local or fail. |
| **BUG-06** | Responsive Sidebar Auto-Collapse | On 13–14" MacBook screens (`< 860pt` width), opening both left and right sidebars simultaneously could squeeze the center PDF canvas unless manually collapsed. | `MainWindowController` observes split view width changes and automatically collapses the secondary inspector first (`< 860pt`), and left sidebar (`< 680pt`), while preserving user manual overrides when space permits. |
| **BUG-07** | Offscreen Capture Black Selection Artifacts | Standard `NSTableRowView` and `NSVisualEffectView` selection layers render solid pitch-black boxes in headless `cacheDisplayInRect:` captures. | `GlassTableRowView` overrides `layout()` to hide private `_NSVisualEffectView` selection subviews and renders a crisp translucent `controlAccentColor` capsule with specular highlight and Increase Contrast accessibility support. |
